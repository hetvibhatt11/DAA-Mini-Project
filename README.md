# DAA-Mini-Project
#  Smart Budget Optimization System

A C++ mini project that helps users select the most important expenses within a fixed budget using **Dynamic Programming**.

###  Features
- Enter total budget and expenses
- Assign priority values from 1 to 10
- Optimize expenses automatically
- Display selected expenses and maximum priority score
- Calculate total spending and remaining budget

###  Technologies
- **Language:** C++
- **Algorithm:** 0/1 Knapsack
- **Concept:** Dynamic Programming

### How to Run
1. Compile the C++ source code.
2. Run the program.
3. Enter your budget and expense details.
4. View the optimized budget results.

###  Complexity
- **Time:** O(n × B)
- **Space:** O(n × B)

### 🎓 Project Details
**Subject:** Design and Analysis of Algorithms (DAA)  
**Project Type:** Mini Project
